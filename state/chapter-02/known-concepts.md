# 讀者已學過的專有名詞清單

- 即時通訊（Real-Time Communication）：資訊產生後，在足以支援互動的時間內持續交換。
- 網頁即時通訊（Web Real-Time Communication, WebRTC）：瀏覽器與相容端點建立即時通訊所需的一組標準化能力與處理模型。
- 對等端（peer）：參與一次即時通訊的一端；不表示資料必然直接傳送。
- 用戶端（client）：在本章 localhost HTTP 情境中，建立一條 connection 的參與者。
- 伺服器（server）：在本章 localhost HTTP 情境中，接受一條 connection 的參與者。
- 網際網路協定位址（IP address）：IPv4 與 IPv6 封包中用來表示來源與目的網路位置的位址。
- 連接埠（port）：在特定傳輸脈絡中，用來識別服務端點的數字欄位。
- 區域網路（LAN）：位於相對有限區域內的一組電腦與其他裝置。
- 廣域網路（WAN）：通常跨較大地理範圍並服務較多獨立使用者的網路。
- 封包（packet）：網路層處理的一個有格式、有限大小資料單位。

讀者另已建立以下非術語心智模型：完成檔案寄送不同於持續雙向互動；證據範圍必須與結論範圍一致；client／server 是 connection 中的角色，不是永久機器種類；IP address 與 port 分別描述位置與入口；LAN／WAN 沒有本章自訂的單一距離門檻；packet 不是送達保證。
