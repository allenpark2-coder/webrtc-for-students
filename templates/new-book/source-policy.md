# 來源、引用與授權政策

## 技術來源

優先使用正式規範、標準、官方 API／SDK 文件、原始研究、官方 release notes 與原始碼。可能變動的主張都記錄版本或日期；找不到可靠來源時標示未知或移除。

## 引用格式

```markdown
- [來源名稱](URL) — 版本／發布日期；查核日期 YYYY-MM-DD；支援的主張。
```

## 圖像與資產

- 第三方或生成圖片登記於 `book/assets/figures/ATTRIBUTION.md`。
- 記錄來源、作者／工具、日期、授權、修改與 prompt／規格。
- 正式圖包含 caption、alt text，不能只靠顏色，並通過灰階檢查。

## Lab 安全

- 只在核准隔離環境執行，不使用 production 或未授權網路。
- 不提交真實憑證、個資或 `.env`。
- 每個故障實驗提供備份、復原、cleanup 與停止條件。
